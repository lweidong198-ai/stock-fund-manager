一、定位与原则WHY

在现有 stock-fund-manager 工作台上迭代升级，不重做。核心解决三件事：不知道何时买卖（择时）、数据不会解读（知识）、情绪化拿不住（纪律）。

铁律：大白话 · 零 API Key · 零门槛 · 描述式不预测 · 准确性第一 · 数据仅供参考不构成建议。

使用场景

盘中实时盯盘买卖决策时刻收盘后复盘定期例行回顾

使用设备

电脑 + 手机都要移动优先 · 桌面清晰

六、交付节奏SHIP

准确性基建→ 统一持仓总览→ 信号灯+检查清单→ 复盘+摘要

按依赖关系排序：准确性基建是所有模块的地基先做；持仓总览是默认首页、最痛点第二做；信号灯依赖估值/资金/技术数据第三做；复盘摘要依赖前两者最后做。

✓ 一件一验：每做完一件部署给你点，可随时叫停。每版改完跑五层测试（含 jsdom 实跑）才交付。
